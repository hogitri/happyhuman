# 2026-10-26 — Landing page: less is more

## What changed
- Restructured the landing page from 8 busy sections to 6 calm ones: hero → values as large type → sessions + practical info → trainer quote → 3 FAQs → final CTA. Removed the header nav links, mobile menu, tabs, icon cards and "Praktisk" section. See [[Features/Landing Page]].
- Added the H monogram as the logo (`LogoMark`, redrawn from the punch card) and a `Visual` component that draws brand illustrations instead of gradient placeholders.
- Headings switched from Bricolage Grotesque to Geist semibold with tight tracking; more white space in `Section`.
- Header CTA is now an outline button, so only one sun button shows per view.
- Copy shortened; `health-content-reviewer` fixes applied (clearer bokmål bio, "utfordre deg" instead of "pushe deg", "kom alene eller ta med en venn").
- `AGENTS.md` Design system: new "less is more" and "visuals carry the page" rules, `Logo`/`LogoMark` and `Visual` in the component table, Geist type scale.

## Why
The user asked for a simpler structure where visuals matter most. The minimal direction also matches the brand explorations ([[Features/Brand Identity]]): a one-colour monogram, plain grotesque type and lots of white space.
