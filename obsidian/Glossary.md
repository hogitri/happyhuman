# Glossary

| Term | Meaning |
|------|---------|
| shadcn/ui | Component collection whose source is copied into the repo by the `shadcn` CLI, rather than installed as a package. |
| Base UI | Unstyled, accessible React component library (`@base-ui/react`) that our shadcn components are built on. |
| base-nova | The shadcn style/preset this project uses (Base UI + neutral theme). |
| Blomvåg | Village on Øygarden, west of Bergen, Norway, where the bootcamp is held. See [[Bootcamp i Blomvåg]]. |
| Bootcamp i Blomvåg | Free community group-training class run by Kaja Haugen. See [[Bootcamp i Blomvåg]]. |
| Blomvåg bhg | Blomvåg Barnehage (kindergarten); its gym hall is the winter venue. |
| Sirkeltrening | Circuit training: rotating through 8–10 exercise stations. |
| Leketreff | Playdate for children, sometimes combined with a session. |
| Mestring / treningsglede | Mastery / joy of training: the trainer's core goals for participants. |
| Økt | A training session. |
| Antidoping Norge | Norway's national anti-doping organisation, where Kaja Haugen works. |
| NIH | Norges idrettshøgskole, the Norwegian School of Sport Sciences. |
| SiO | Studentsamskipnaden i Oslo og Akershus, the Oslo student welfare organisation; where Kaja worked 2014–2021. |
| Atlas Accelerator | Bergen startup accelerator (atlasaccelerator.no) co-founded by Hoang in 2024; DNB is a partner. |
| Agens | Company where Hoang is Head of Ventures. |
| Firi | Startup Hoang co-founded (2018–2021). |
